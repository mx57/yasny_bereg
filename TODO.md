# Итог работ по «Ясному Берегу»

## Готово (итерация 1)
- Каталог содержит 35 образовательных материалов (было 6; около 5,8×), 104 практики (было 14; около 7,4×), 173 мотивационных послания/мысли/собирательных примера (было 31; около 5,6×) и 14 карточек добавок (было 8).
- Суммарно по этим четырём разделам: 326 записей вместо 59 — примерно 5,5×. Новые тексты авторские, ID практик уникальны; медицинские материалы снабжены источниками и оговорками.
- Добавлены четыре настраиваемых дневных слота мотивационных уведомлений, выключение/включение и восстановление расписания после перезагрузки, смены времени или часового пояса.
- Главный экран показывает разную поддержку утром, днём и вечером. Каталоги получили поиск, фильтры и компактное раскрытие карточек.
- Удалены вымышленные отзывы, псевдоклинические оценки и неподтверждённые обещания от практик/добавок. Упрощены главный экран, окно помощи и дневник измерений.

## Готово (итерация 2 — текущая)
- **Исправлены сломанные юнит-тесты**: ожидания не сходились с фактическим каталогом (группы Джекобсона 4 против 6, миф-карточки 8 против 6, тема MECHANISMS не была покрыта, тест проверял несуществующую строку «7 дн.»). Тесты переписаны под реальные инварианты.
- **Исправлен баг с чистым спиртом**: значение `daily_ethanol_ml` сохранялось, но никогда не загружалось из prefs, а ввести его в UI было невозможно — на главном экране вечно висело «Данные не введены». Теперь поле есть в настройках счётчика, значение сохраняется и считается.
- **Ротация мотивации по дням**: послание дня, мысль и собирательный пример больше не «застывают» на одной карточке до смены состояния — подборка из топ-7 кандидатов ротируется ежедневно (стабильно в течение дня, обновляется около полуночи).
- **BLE**: добавлены проверки runtime-разрешений и защита от SecurityException при отзыве разрешения во время сканирования/подключения; кнопка сохранения замера перестала быть заглушкой — пульс и HRV с датчика сохраняются в журнал здоровья (давление честно не подставляется).
- **Честность замеров**: давление 0 больше не превращается молча в 70/40 — 0 означает «не измерено» и так и отображается в отчёте для врача.
- **Ночная поддержка**: для часов 0–4 отдельный блок с инструкцией о безопасности (вместо «вечернего» текста).
- **Уникальные ID уведомлений** вместо таймстампа по модулю 10 000 (раньше подряд отправленные уведомления перезаписывали друг друга).
- **Расширение базы контента**: 50 статей (+15, включая 6 новых по механизмам зависимости), ~134 практики (+30), ~210 мотивационных записей (+37), 20 карточек добавок (+6), 13 миф-карточек (+5), ПМР Джекобсона расширена до 10 групп мышц, добавлены достижения 90/180/365 дней.
- **CI**: добавлен gradle wrapper (его не было в репозитории) и workflow `.github/workflows/android-apk.yml` — сборка debug+release APK, юнит-тесты, публикация в Artifacts, роллинг-pre-release `ci-latest` из main и релизы по тегам `v*`.
- **README.md** написан с нуля (раньше не было), обновлён metadata.json (убрано упоминание несуществующего «мониторинга стресса»), версия поднята до 1.2 (versionCode 3).

## Выпуск APK
- Workflow собирает оба APK и публикует их в GitHub Releases (pre-release `ci-latest` из main; полноценные релизы по тегам `v*`) и в Artifacts.
- Для стабильной подписи release-сборки задайте секреты `KEYSTORE_BASE64`, `STORE_PASSWORD`, `KEY_PASSWORD`; без них используется одноразовый ключ CI.
- Исторические APK в `releases/` оставлены как есть; новые сборки каналом APK теперь является GitHub Releases, чтобы не раздувать репозиторий.

## Проверки
- Юнит-тесты обновлены и расширяются: ротация, уникальность ID всех каталогов, расчёт RMSSD, ночная поддержка, достижения.
- CI прогоняет `testDebugUnitTest` на каждый PR и push.
- Медицинские источники и редакционные ограничения находятся в `docs/content-safety-sources.md`.
