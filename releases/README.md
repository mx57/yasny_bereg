# Релизы приложения «Ясный Берег» (v1.0)

В этой папке находятся готовые к установке на Android-смартфон или планшет подписанные APK-файлы приложения **«Ясный Берег»** (`com.aistudio.soberhelper.ybkrvq`):

- **`yasny-bereg-v1.0.apk`** — основной установочный пакет приложения (подписан ключом сборки, готов к установке на телефон).
- **`app-debug.apk`** — копия собранного APK со стандартным именем.

## Как скачать и установить APK
1. В левой панели проводника файлов AI Studio откройте папку **`releases/`**.
2. Нажмите правой кнопкой мыши (или на значок меню рядом с файлом) на **`yasny-bereg-v1.0.apk`** и выберите **Download (Скачать)**, либо экспортируйте проект целиком через меню **Download ZIP / Export**.
3. Перенесите скачанный `.apk` файл на телефон Android и откройте его для установки (разрешив установку из этого источника при запросе системы).
