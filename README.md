# Ясный Берег

Оффлайн-помощник для тех, кто сокращает или прекращает употребление алкоголя. Приложение работает полностью на устройстве: без аккаунтов, без аналитики и без отправки данных на сервер. Личные записи шифруются через AndroidKeyStore (AES-256-GCM).

> **Важно.** Приложение не является медицинским изделием, не ставит диагнозов и не заменяет помощь специалиста. Резкое прекращение употребления при физической зависимости может быть опасным — план прекращения обсуждается с врачом. При судорогах, галлюцинациях, спутанности сознания или других тяжёлых симптомах вызывайте местную экстренную службу.

## Возможности

- **Счётчик трезвости и трекер** — дни трезвости, сэкономленные деньги и оценка «непитого» чистого спирта по вашим исходным данным.
- **Адаптивная мотивация** — послания, мысли и собирательные примеры подбираются под этап трезвости, состояние и уровень тяги; подборка ротируется каждый день.
- **Каталог методов** — 130+ практик (КПТ, саморегуляция, планирование, ситуации риска), прогрессивная мышечная релаксация по Джекобсону с таймером, заземление 5-4-3-2-1, разбор мифов.
- **Библиотека знаний** — 50 статей по 11 темам: триггеры, механизмы зависимости, безопасность при отмене, варианты помощи, сон, питание и др. Все материалы снабжены ссылками на официальные источники (NIAAA, NICE, NHS, ASAM, SAMHSA, NIH ODS, NCCIH).
- **Дневник самочувствия** — эмоция, тяга 0–10, сон, симптомы и комментарий; всё шифруется на устройстве.
- **Журнал здоровья** — пульс с Bluetooth-датчиков (стандартный профиль Heart Rate 0x180D), HRV по RR-интервалам, ручной ввод давления и пульса.
- **Экспорт отчёта для врача** — HTML-отчёт с дневником и замерами (печать / PDF / отправка).
- **Карточки добавок** — 20 честных карточек без рекламных обещаний: что известно науке, а что нет.
- **Ежедневные напоминания** — до 4 настраиваемых слотов, восстановление расписания после перезагрузки.
- **Достижения** — вехи 1/7/14/30/90/180/365 дней и прогресс по практикам, материалам и записям.
- **Крупный шрифт** — режим для пожилых пользователей.

## Технологии

- Kotlin, Jetpack Compose (Material 3)
- Room (локальная БД), ViewModel + StateFlow
- AndroidKeyStore (AES-256-GCM) для личных записей
- Bluetooth LE GATT (Heart Rate profile)
- minSdk 24, targetSdk 36

## Сборка

Требуется JDK 17+ и Android SDK (platform 36).

```bash
# Отладочная сборка (нужен debug.keystore в корне, пароль android, alias androiddebugkey)
keytool -genkeypair -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android \
  -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
./gradlew assembleDebug

# Release-сборка: KEYSTORE_PATH / STORE_PASSWORD / KEY_PASSWORD (см. app/build.gradle.kts)
KEYSTORE_PATH=$PWD/my-upload-key.jks STORE_PASSWORD=... KEY_PASSWORD=... ./gradlew assembleRelease

# Юнит-тесты
./gradlew testDebugUnitTest
```

## CI / APK

В репозитории настроен workflow `.github/workflows/android-apk.yml`:

- на каждый push/PR собирает debug- и release- APK и прогоняет юнит-тесты;
- APK публикуются в Artifacts сборки;
- push в `main` обновляет pre-release **ci-latest** с обоими APK и контрольными суммами;
- тег `v*` создаёт полноценный Release.

Для стабильной подписи release-сборки задайте в секретах репозитория `KEYSTORE_BASE64` (base64 вашего `my-upload-key.jks`), `STORE_PASSWORD`, `KEY_PASSWORD`. Без секретов сборка подписывается одноразовым ключом: APK устанавливается, но обновить «поверх» предыдущей версии с другой подписью нельзя.

## Принципы контента

- Никаких выдуманных отзывов, «историй пациентов» и неподтверждённых обещаний — только авторские тексты и явно помеченные собирательные примеры.
- Медицинские утверждения даются с оговорками и ссылками на официальные источники; их список — в `docs/content-safety-sources.md`.
- Карточки добавок описывают доказательства честно, включая отсутствие пользы.
- Приложение не рассчитывает «стресс-индексы» и не делает вид, что измеряет риск срыва: замеры остаются наблюдениями пользователя.

## Источники

Основные источники контента: NIAAA, NICE (CG100), NHS, ASAM, SAMHSA, NIH Office of Dietary Supplements, NCCIH, MedlinePlus. Полный редакционный регламент — в `docs/content-safety-sources.md`.
